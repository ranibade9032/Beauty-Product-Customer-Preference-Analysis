# Beauty Product Customer Preference Analysis

## Project Overview

This project focuses on analyzing customer preferences for beauty products using Data Science and Python.

## Objectives

* Understand customer preferences.
* Identify factors influencing beauty product selection.
* Analyze product categories, prices, and ratings.
* Discover patterns using data analysis.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook
